# Court brief fixtures

`26a305.txt` is the full text extracted with `unpdf` from the Court's
[September 14, 2026 PDF](https://www.supremecourt.gov/opinions/25pdf/26a305_4g15.pdf).
It contains the stay denial, Kavanaugh concurrence, and Alito dissent. The
fixture output is handwritten test data, not a claimed successful paid generation.

The merits and separate-document examples in `court-brief-fixtures.ts` are
explicitly synthetic. They isolate holdings, unknowns, document attribution,
and quote verification without relying on live discovery or spending provider credit.
