## Actual observations

- This isolated worktree had no root `.env` or `.env.local`, and no process
  `GOOGLE_CIVIC_API_KEY`. The [initial harness run](2026-09-15.json) recorded
  all 15 rows as `not_measured / missing_credential`; no requests were sent.
- With coordinator authorization, inspected only the Civic variable in the original
  checkout's root environment files. A key was configured. Loaded it through the
  existing `loadRepoEnv` loader, which preserves process precedence and checks
  `.env.local` before `.env`. No credentials or environment files were copied.
- Two bounded GET probes to `www.googleapis.com/civicinfo/v2/elections` returned
  HTTP 403. The first, at 00:18:37 UTC, reported `PERMISSION_DENIED` and
  `accessNotConfigured`; the [reproducible probe](2026-09-15-endpoint.json)
  confirmed `api_access_not_configured`. This does not establish key invalidity.
  No voter-info calls followed because configured API access was blocked.
- No database target was used or connected. No enrichment, Places calls, cache
  writes, migration, registration submission, or deployment occurred.

## Endpoint-specific official evidence

Official pages were retrieved on 2026-09-15 UTC:

- [Google API reference](https://developers.google.com/civic-information/docs/v2)
  lists GET `/elections` and GET `/voterinfo`. Documentation availability is not
  successful credentialed access or ballot coverage.
- [Google's Representatives retirement notice](https://groups.google.com/g/google-civicinfo-api/c/9fwFn-dhktA)
  scopes the retirement to Representatives and states Elections and Divisions are
  unaffected. The [March 25, 2025 reminder](https://groups.google.com/g/google-civicinfo-api/c/lR8kT7Uc0sE)
  names April 30, 2025 as the retirement date. A blanket Google Civic sunset claim
  is unsupported by these sources. This report does not assess Places migration.
- [Voter-info reference](https://developers.google.com/civic-information/docs/v2/elections/voterInfoQuery)
  describes address-specific alternatives and a second request with an explicit
  election ID. Same-day alternatives can suppress contests and polling details
  until disambiguated. Missing details cannot by themselves establish publication
  status. These rules drive the harness's conservative selection state.
